# Tic-Tac-Toe AI Project

This is a simple implementation of the Tic-Tac-Toe game where a human player can play against an AI. The AI uses the minimax algorithm to determine the best move in the game.

## Features
- **Play as either 'X' or 'O'**: You can choose to play as 'X' (where you start) or 'O' (where the AI starts).
- **AI with Minimax Algorithm**: The AI evaluates all possible moves and chooses the optimal one to win or block the opponent.
- **Terminal Display**: The game is played in the terminal, and the board is displayed after each move.

## How to Play
1. Run the game using Python.
2. Choose your character ('X' or 'O').
3. Take turns with the AI to place your mark on the board.
4. The game will end when there is a winner or a draw.

## Running the Game
To run the game, execute the following command in the terminal:
```
python tic_tac_toe.py
```
